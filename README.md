# Keenious — инвестиционный тизер (лендинг)

Учебный проект: одностраничный лендинг на основе инвестиционного тизера Keenious AS,
подготовленного для АО «Антиплагиат» как потенциального стратегического инвестора.
Не является документом Keenious AS или АО «Антиплагиат»; параметры раунда, рыночные
оценки и сценарии интеграции — допущения автора.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Лендинг: вся вёрстка, стили и скрипты в одном файле |
| `favicon.svg` | Иконка вкладки браузера |
| `README.md` | Это описание |

## Доступ

Страница открывается с формой пароля. В коде хранится только SHA-256-хеш пароля;
пароль сообщается получателю отдельно. Это демонстрационная защита: текст страницы
можно прочитать в исходном коде.

## Публикация на GitHub Pages

1. Загрузите файлы в корень репозитория (Add file → Upload files → Commit changes).
2. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
3. Через 1–3 минуты сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.
